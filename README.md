# Простой калькулятор на Python

## Описание
Консольный калькулятор, который принимает два числа от пользователя и выполняет различные арифметические операции.

## Особенности
- Сложение (`+`)
- Вычитание (`-`)
- Умножение (`*`)
- Деление (`/`)
- Целочисленное деление (`//`)
- Остаток от деления (`%`)
- Возведение в степень (`**`)

## Требования
- Python 3.x

## Установка
1. Склонируйте репозиторий или скачайте файл `calculator.py`.
2. Убедитесь, что у вас установлен Python 3.

## Использование
Запустите скрипт:
```bash
python calculator.py
```
Программа запросит ввод двух чисел и выведет результаты всех поддерживаемых операций.

### Пример работы
```
Введите первое число: 10
Введите второе число: 3
Сложение: 13.0
Вычитание: 7.0
Умножение: 30.0
Деление: 3.3333333333333335
Целочисленное деление: 3.0
Остаток от деления: 1.0
Возведение в степень: 1000.0
```

## Поддерживаемые операции
| Операция | Символ | Описание               |
|----------|--------|------------------------|
| Сложение | `+`    | a + b                  |
| Вычитание| `-`    | a - b                  |
| Умножение| `*`    | a * b                  |
| Деление  | `/`    | a / b                  |
| Целочисленное деление | `//` | a // b          |
| Остаток от деления | `%` | a % b               |
| Возведение в степень | `**` | a ** b            |
