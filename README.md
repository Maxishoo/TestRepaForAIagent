# Простой калькулятор на Python

## Описание
Простой консольный калькулятор, который принимает два числа от пользователя и выполняет основные арифметические операции: сложение, вычитание, умножение и деление.

## Требования
- Python 3.x

## Установка
1. Склонируйте репозиторий или скачайте файл `calculator.py`.
2. Убедитесь, что у вас установлен Python 3.

## Использование
Запустите скрипт:
```bash
python calculator.py
```
Программа запросит ввод двух чисел и выведет результаты всех операций.

### Пример работы
```
Введите первое число: 10
Введите второе число: 5
Сложение: 15.0
Вычитание: 5.0
Умножение: 50.0
Деление: 2.0
```
