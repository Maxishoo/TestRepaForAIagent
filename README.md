# Simple Calculator

## Description
A simple command-line calculator implemented in Python that supports basic arithmetic operations: addition, subtraction, multiplication, and division.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Continuous operation until user chooses to exit
- Error handling for invalid inputs and division by zero

## Usage
1. Ensure you have Python 3.x installed.
2. Save the calculator script as `calculator.py`.
3. Run the script from a terminal:
   ```
   python calculator.py
   ```
4. Follow the prompts:
   - Enter the first number.
   - Choose an operation (+, -, *, /).
   - Enter the second number.
   - View the result.
   - Type 'exit' at any prompt to quit.

## Example
```
Enter first number (or 'exit' to quit): 10
Enter operation (+, -, *, /): *
Enter second number: 5
Result: 50.0
```
